**src/contract-tests.ts:** This is the core implementation. Export a `runContractTests(connector: ConnectorDefinition)` function that uses Vitest's `describe/it/expect` to generate contract test suites:

Contract checks (all derived from `ConnectorDefinition` and `ActionDefinition` interfaces in `@feelr/connector-sdk`):

1. `name` matches `/^[a-z][a-z0-9-]*$/` (lowercase, alphanumeric + hyphens)
2. `display_name` is non-empty string
3. `version` matches semver pattern `/^\d+\.\d+\.\d+/`
4. `auth_type` is one of: `'api_key' | 'oauth2' | 'bearer_token' | 'none'`
5. `actions` is non-empty (at least one action registered)
6. For each action:
   - `name` contains a dot (dot notation like `items.list`)
   - `description` length is between 10 and 300 characters
   - `returns` is `'list'` or `'single'`
   - `handler` is a function (typeof === 'function')
   - Each `param` in `params` array has: non-empty `name`, valid `type` ('string'|'number'|'boolean'), boolean `required`, non-empty `description`

Structure the tests as nested `describe` blocks:
```
describe(`SDK Contract: ${connector.name}`, () => {
  it('has a valid name', ...)
  it('has a non-empty display_name', ...)
  ...
  describe('actions', () => {
    describe(actionName, () => {
      it('uses dot notation', ...)
      ...
    })
  })
})
```

**src/index.ts:** Public API -- re-export `runContractTests` as `validateConnector`:
```typescript
export { runContractTests as validateConnector } from './contract-tests'
```

After creating the package, run `pnpm install` to register the workspace package.

**Create `scripts/create-connector.mjs`:** A ~100-line Node.js script that:

1. Parses CLI args: positional `name`, optional `--auth <type>` flag (default: `bearer_token`)
2. Validates name: must match `/^[a-z][a-z0-9-]*$/`, must not be `_template`, must not already exist
3. Validates auth type: must be one of `api_key`, `oauth2`, `bearer_token`, `none`
4. Copies `connectors/_template/` to `connectors/<name>/` using `fs.cp()` with `recursive: true`
   - Filter function to exclude `node_modules/` and `.turbo/` directories
5. Performs string replacements in `.ts`, `.json`, `.md` files only (research pitfall #5):
   - `@feelr/connector-template` -> `@feelr/connector-<name>`
   - `templateConnector` -> `<camelName>Connector` (e.g., `todoistConnector`)
   - `Template Connector` -> `<PascalName> Connector` (e.g., `Todoist Connector`)
   - `name: 'template'` -> `name: '<name>'`
   - `auth_type: 'bearer_token'` -> `auth_type: '<auth_type>'` (only if auth != bearer_token)
6. Runs `pnpm install` via `execSync` to register the new workspace package
7. Prints next steps: cd into directory, edit actions, run tests

Helper function `toPascalCase(str)`: splits on hyphens, capitalizes first letter of each segment.
Helper function `toCamelCase(str)`: PascalCase but lowercase first letter.

Only replace in files with extensions `.ts`, `.json`, `.md`. Use a Set of replaceable extensions. Walk the directory recursively, skip `node_modules` and `.turbo` and any dot-directories.

**Update root `package.json`:** Add script:
