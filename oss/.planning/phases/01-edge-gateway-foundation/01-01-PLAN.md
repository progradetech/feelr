  <action>
    Implement the complete Connector SDK package. This is the type contract for the entire project. Reference RESEARCH.md Pattern 4 for the exact interface shapes.

    **types.ts -- Connector and Action interfaces (CONN-05, CONN-06):**
    - `ConnectorDefinition`: name (lowercase string), display_name, version, auth_type ('oauth2' | 'api_key' | 'bearer_token' | 'none'), actions (Record of string to ActionDefinition)
    - `ActionDefinition`: name (dot notation like "issues.list"), description (50-100 tokens, agent-optimized), params (ParamDefinition[]), returns ('list' | 'single'), handler (function taking ActionContext returning Promise of ActionResult)
    - `ActionContext`: params (Record of string to unknown), fetch (typeof globalThis.fetch -- Web Standard API only per CONN-06), credential (optional string, undefined in Phase 1)
    - `ActionResult`: data (Record[] for lists OR Record for single items), meta (optional: cursor, has_more, total_count), raw (optional unknown for ?raw=true)
    - `ParamDefinition`: name (snake_case), type ('string' | 'number' | 'boolean'), required (boolean), description (string), default (optional)
    - CRITICAL: No imports from hono, wrangler, cloudflare, or apps/gateway. Only Web Standard APIs and Zod.

    **envelope.ts -- Response type definitions (GATE-02):**
    - `FeelrResponse<T>`: { ok: true, data: T, meta: ResponseMeta }
    - `FeelrErrorResponse`: { ok: false, error: { code: string, message: string, detail?: string, hint: 'retry' | 'auth' | 'abort', status: number } }
    - `ResponseMeta`: { request_id: string, connector: string, action: string, duration_ms: number, cursor?: string, has_more?: boolean }
    - Per user decision: envelope is always { ok, data, error, meta }. Pagination lives inside meta (per research recommendation).

    **errors.ts -- Error code enum and FeelrError class (GATE-03):**
    - `ErrorCode` type union: CONNECTOR_NOT_FOUND, ACTION_NOT_FOUND, VALIDATION_ERROR, AUTH_REQUIRED, AUTH_INVALID, FORBIDDEN, UPSTREAM_ERROR, UPSTREAM_TIMEOUT, RATE_LIMITED, INTERNAL_ERROR, NOT_FOUND
    - `Hint` type: 'retry' | 'auth' | 'abort' (per locked decision: three hints only)
    - `FeelrError` class extending Error:
      - constructor(code: ErrorCode, options: { message: string, hint: Hint, status: 400|401|403|404|429|500|502, detail?: string })
      - Getters for hint, status, detail
      - Per locked decision: Feelr-authored message + upstream message in detail field
      - Per locked decision: HTTP status from normalized set (400, 401, 403, 404, 429, 500, 502)
    - Use SCREAMING_SNAKE_CASE for error codes (per research recommendation for namespaced strings)

    **validation.ts -- Shared Zod schemas:**
    - Import z from 'zod' (Zod 4 -- use z.strictObject() NOT z.object().strict() per research pitfall)
    - `responseMetaSchema`: Zod schema matching ResponseMeta
    - `errorSchema`: Zod schema matching the error object shape
    - `successResponseSchema`: Zod schema for FeelrResponse (generic T as z.unknown())
    - `errorResponseSchema`: Zod schema for FeelrErrorResponse
    - These schemas will be used by @hono/zod-openapi for automatic OpenAPI doc generation

    **index.ts -- Barrel export:**
    - Re-export everything from types.ts, envelope.ts, errors.ts, validation.ts
    - This is the public API surface of @feelr/connector-sdk

    After implementation, run `pnpm turbo typecheck` to verify TypeScript compilation succeeds across the workspace.
