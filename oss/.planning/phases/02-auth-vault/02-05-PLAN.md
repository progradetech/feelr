Test the crypto module (encrypt, decrypt, hashToken) using the Workers test environment.

```typescript
import { describe, it, expect } from 'vitest'
```

Tests (8-10 tests):
- `encrypt/decrypt round-trips a simple string` -- encrypt("hello world", masterSecret), decrypt should return "hello world"
- `encrypt/decrypt round-trips a JSON credential payload` -- encrypt(JSON.stringify({accessToken: "tok_abc", refreshToken: "ref_xyz"})), decrypt and parse should match
- `encrypt produces different ciphertext for same plaintext` -- two encrypts of same string produce different base64 (random IV)
- `decrypt fails with wrong master secret` -- encrypt with key A, decrypt with key B throws
- `decrypt fails with corrupted ciphertext` -- modify the base64 string, decrypt throws
- `encrypt/decrypt with different purposes produce independent ciphertext` -- encrypt(same text, same key, "purpose-a") vs "purpose-b" produce different output, each decrypts with its own purpose
- `hashToken produces consistent hex output` -- hashToken("test") called twice returns same hex string
- `hashToken produces 64-character hex string` -- SHA-256 = 32 bytes = 64 hex chars
- `hashToken produces different output for different inputs` -- hashToken("a") !== hashToken("b")

Use a test master secret: `const MASTER_SECRET = 'test-master-secret-at-least-32-chars-long'`
