<task type="checkpoint:human-action" gate="blocking">
  <name>Task 2: Fix Cloudflare API token and create GitHub PAT</name>
  <files></files>
  <action>
Two dashboard actions are needed that Claude cannot perform. The user must complete both before proceeding.

**Action A: Fix Cloudflare API Token (CICD-01)**

1. Go to Cloudflare Dashboard > My Profile > API Tokens
2. Find the token used for CI deployments (the one stored as CLOUDFLARE_API_TOKEN in GitHub secrets)
3. Click "Edit" (or recreate if edit is unavailable)
4. Ensure ALL of these permissions are present:
   - Workers Scripts: Account: Edit
   - Workers KV Storage: Account: Edit
   - D1: Account: Edit
   - Account Settings: Account: Read
   - Workers Routes: Zone (feelr.dev): Edit
5. Save the token
6. If the token value changed (i.e., you had to recreate it), update the CLOUDFLARE_API_TOKEN secret in GitHub repo settings at https://github.com/progradetech/feelr/settings/secrets/actions

**Action B: Create Fine-Grained PAT for New Tap**

1. Check progradetech org settings: GitHub > progradetech org > Settings > Personal Access Tokens > Settings
   - Ensure "Allow access via fine-grained personal access tokens" is enabled
   - If not available, use a classic PAT with `repo` scope instead (less ideal but functional)
2. Go to GitHub > Settings > Developer Settings > Personal Access Tokens > Fine-grained tokens
3. Click "Generate new token"
4. Token name: `goreleaser-homebrew-tap`
5. Expiration: 90 days (or custom -- you will need to rotate this)
6. Resource owner: `progradetech`
7. Repository access: Only select repositories > `progradetech/homebrew-feelr`
8. Permissions:
   - Contents: Read and write
   - Metadata: Read (auto-selected)
9. Generate token and copy the value
10. Go to https://github.com/progradetech/feelr/settings/secrets/actions
11. Update the `HOMEBREW_TAP_GITHUB_TOKEN` secret with the new PAT value
  </action>
