2. Check the current formula to find the latest version and SHA256 checksums:
   ```

   ```
   Extract the current `version`, URLs, and `sha256` values. These will be preserved in the deprecation formula so existing users still get a working binary.

3. If `Formula/feelr.rb` does not exist (no releases have been published yet), check if the repo has ANY formula file. If the repo is completely empty or has no formula, create a minimal deprecation stub:
   ```ruby
   class Feelr < Formula
     desc "Agent-friendly API simplification layer CLI (DEPRECATED TAP)"
     homepage "https://feelr.dev"
     # No URL -- this tap is deprecated. Install from the new tap:
     #   brew install progradetech/feelr/feelr
     version "0.0.0"
     sha256 ""

     deprecate! date: "2026-02-10", because: "tap moved to progradetech/feelr"

     def install
       odie "This tap is deprecated. Install from the new tap:\n\n  brew untap andrewprograde/feelr\n  brew install progradetech/feelr/feelr"
     end

     def caveats
       <<~EOS
         This tap (andrewprograde/feelr) is deprecated.

         To switch to the new tap, run:

           brew untap andrewprograde/feelr
           brew install progradetech/feelr/feelr

         Future releases will only be published to progradetech/feelr.
       EOS
     end
   end
   ```

4. If the formula DOES exist with real URLs and checksums, replace it with the deprecation version that PRESERVES the download URLs and checksums (so `brew upgrade` still works but shows the warning):
   ```ruby
   class Feelr < Formula
     desc "Agent-friendly API simplification layer CLI (DEPRECATED TAP)"
     homepage "https://feelr.dev"

     # Preserved from last GoReleaser push -- users can still install/upgrade
     # [Keep existing on_macos/on_linux/url/sha256 blocks from current formula]

     deprecate! date: "2026-02-10", because: "tap moved to progradetech/feelr"

     def install
       bin.install "feelr"
     end

     def caveats
       <<~EOS
         This tap (andrewprograde/feelr) is deprecated.

         To switch to the new tap, run:

           brew untap andrewprograde/feelr
           brew install progradetech/feelr/feelr

         Future releases will only be published to progradetech/feelr.
       EOS
     end
   end
   ```

   ```
   git commit -m "deprecate: direct users to progradetech/feelr tap"
   git push origin main
   ```

6. Clean up:
   ```
   rm -rf /tmp/old-homebrew-tap
   ```
