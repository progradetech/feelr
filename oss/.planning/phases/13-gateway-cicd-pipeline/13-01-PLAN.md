<task type="auto">
  <name>Task 2: Create CI workflow for PR checks and staging preview deploy</name>
  <files>.github/workflows/ci.yml</files>
  <action>
    Create `.github/workflows/ci.yml` with two jobs:

    **Job 1: `check`** (runs on every PR)
    - Trigger: `pull_request` types `[opened, synchronize]`
    - Concurrency: group `ci-${{ github.head_ref }}`, cancel-in-progress: true
    - Steps:
      1. `actions/checkout@v4` with `fetch-depth: 0` (needed for turbo --affected)
      2. `pnpm/action-setup@v4` (auto-reads packageManager from package.json)
      3. `actions/setup-node@v4` with `node-version: 20` and `cache: 'pnpm'`
      4. `pnpm install --frozen-lockfile`
      5. Cache Turborepo: `actions/cache@v4` with path `.turbo`, key `${{ runner.os }}-turbo-${{ github.sha }}`, restore-keys `${{ runner.os }}-turbo-`
      6. Run `pnpm turbo run lint typecheck test --affected`
    - timeout-minutes: 15

    **Job 2: `gateway-preview`** (deploys gateway changes to staging for preview)
    - needs: check
    - Concurrency: group `deploy-staging`, cancel-in-progress: false (IMPORTANT: same group as deploy-staging.yml to prevent staging deploy races per Pitfall 4)
    - Steps:
      1. `actions/checkout@v4`
      2. `dorny/paths-filter@v3` to check if gateway code changed (paths: `apps/gateway/**`, `packages/**`, `connectors/**`)
      3. If gateway changed: `pnpm/action-setup@v4`, `actions/setup-node@v4` with node 20 + pnpm cache, `pnpm install --frozen-lockfile`
      4. If gateway changed: `cloudflare/wrangler-action@v3` with `command: deploy --env staging`, `workingDirectory: apps/gateway`, `packageManager: pnpm`, secrets `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`
      5. If gateway changed: `actions/github-script@v7` to create PR comment with staging preview URL `https://feelr-gateway-staging.feelr.workers.dev`
    - timeout-minutes: 10

    Key points:
    - Do NOT use `wrangler versions upload` for preview -- DO Workers don't support preview URLs (Pitfall 1)
    - Use `packageManager: pnpm` in wrangler-action to use project's wrangler version (Pitfall 7)
    - The gateway-preview job uses the `deploy-staging` concurrency group to serialize with main-branch staging deploys (Pitfall 4)
  </action>
  <verify>

    Verify the file contains: pull_request trigger, concurrency groups, turbo run lint typecheck test --affected, wrangler deploy --env staging, PR comment step.
