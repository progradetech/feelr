  <action>
    1. Create `apps/dashboard/src/lib/auth.ts`:
    - `getAdminToken(): string | null` -- reads from localStorage key `feelr_admin_token`.
    - `setAdminToken(token: string): void` -- writes to localStorage.
    - `clearAdminToken(): void` -- removes from localStorage.
    - Guard all localStorage calls with `typeof window !== 'undefined'` check for SSG compatibility.

    2. Create `apps/dashboard/src/lib/api.ts`:
    - Export `gatewayFetch<T>(path: string, options?: RequestInit): Promise<T>`.
    - Reads token via `getAdminToken()`. If no token, throws `new Error('Not authenticated')`.
    - Calls `fetch(GATEWAY_URL + path, { ...options, headers: { 'Content-Type': 'application/json', 'Authorization': 'Bearer ' + token, ...options?.headers } })`.
    - Parses response JSON. If `!body.ok`, throws `new Error(body.error?.message || 'Gateway request failed')`.
    - Returns `body.data as T`.
    - Also export `gatewayMutate<T>(path: string, method: string, body?: unknown): Promise<T>` for POST/DELETE operations that serializes body as JSON.

    3. Create `apps/dashboard/src/components/auth-guard.tsx`:
    - 'use client' component.
    - On mount (useEffect), check `getAdminToken()`. If null, `router.replace('/login')`. If present, set `isAuthed` state to true.
    - While not authed, render null (or a minimal loading spinner with zinc-800 background).
    - When authed, render children.

    4. Create `apps/dashboard/src/app/login/page.tsx`:
    - 'use client' page.
    - Centered card with Feelr logo/title, an input for admin token, and a "Sign In" button.
    - On submit: call `gatewayFetch('/admin/keys')` with the entered token (set it temporarily to test validity). If the request succeeds, store the token with `setAdminToken()` and `router.push('/overview')`. If it fails, show an error toast via sonner.
    - Include a note: "Get your admin token from `feelr init` in the CLI."
    - If already authenticated (token exists), redirect to /overview immediately.

    5. Create `apps/dashboard/src/components/sidebar.tsx`:

    - Footer: "Logout" button that calls `clearAdminToken()` and `router.push('/login')`.
    - Dark theme: bg-zinc-900 sidebar, zinc-400 text for inactive links, white text for active.
