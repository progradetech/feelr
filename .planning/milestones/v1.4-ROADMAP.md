## Key Decisions

- Fresh snapshot (no git history) for public repo to prevent secret leakage
- Provider registry pattern for billing boundary (BillingProvider interface)
- Git subtree (not submodule) for cloud repo consuming public repo at oss/ prefix
- Cross-repo dispatch via PAT for automated sync on public merges
- Strictly sequential phases — each gates the next

## Issues Resolved

- Billing code fully isolated from open-source codebase
- 10 secrets rotated after public repo creation
- Cloud repo builds independently with overlay pattern
