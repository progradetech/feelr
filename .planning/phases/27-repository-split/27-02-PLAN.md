  <files>/tmp/feelr-public/.git/</files>
  <action>
Create the public GitHub repo and push the prepared snapshot from Plan 01.

1. Create the public repo on GitHub:
   ```bash
   gh repo create progradetech/feelr \
     --public \
     --description "Agent-friendly API simplification layer" \
     --license MIT
   ```
   If the repo already exists (gh returns error), skip creation.

2. Initialize git in the staging area and push:
   ```bash
   cd /tmp/feelr-public
   git init -b main
   git add -A
   git commit -m "Initial release: Feelr v1.0 - Agent-friendly API simplification layer

Open-source edge gateway + Go CLI + web dashboard for AI agent API access.
MIT License."
   git remote add origin git@github.com:progradetech/feelr.git
   git push -u origin main --force
   ```
   Note: `--force` is needed because `gh repo create --license MIT` creates an initial commit with just the LICENSE file. The force push replaces it with the full snapshot. This is safe because the repo was just created.

3. Verify the repo is accessible:
   ```bash
   gh repo view progradetech/feelr --json name,isPrivate,licenseInfo
   ```
   Should show: name=feelr, isPrivate=false, license=MIT

<task type="auto">
  <name>Task 2: Create cloud repo with subtree integration</name>
  <files>/tmp/feelr-cloud/.git/</files>
  <action>
Create the private cloud repo and embed the public repo as a git subtree.

1. Create the private repo on GitHub:
   ```bash
   gh repo create progradetech/feelr-cloud \
     --private \
     --description "Feelr cloud billing overlay"
   ```

2. Disable squash merge to protect subtree markers (per research -- GitHub squash merge corrupts git-subtree-dir markers via CRLF injection):
   ```bash
   gh repo edit progradetech/feelr-cloud --enable-squash-merge=false
   ```

3. Clone the cloud repo locally and set up subtree:
   ```bash
   cd /tmp
   gh repo clone progradetech/feelr-cloud
   cd /tmp/feelr-cloud

   # If repo is empty (no commits), create an initial commit
   if ! git log --oneline -1 2>/dev/null; then
     echo "# Feelr Cloud" > README.md
     echo "" >> README.md
     echo "Private cloud billing overlay for [Feelr](https://github.com/progradetech/feelr)." >> README.md
     git add README.md
     git commit -m "Initial commit: Feelr cloud overlay repo"
     git push -u origin main
   fi
   ```

4. Add the OSS repo as a subtree at oss/ prefix:
   ```bash
   cd /tmp/feelr-cloud
   git remote add oss git@github.com:progradetech/feelr.git
   git fetch oss
   git subtree add --prefix=oss oss main --squash \
     -m "Add progradetech/feelr as OSS subtree at oss/"
   ```

5. Verify subtree markers:
   ```bash
   git log --format='%B' -1 | grep 'git-subtree-dir: oss'
   ```

6. Push the subtree integration:
   ```bash
   git push origin main
   ```
  </action>
