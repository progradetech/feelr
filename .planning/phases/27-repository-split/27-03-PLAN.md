**B. Create gateway-entry.ts** at `cloud/gateway/gateway-entry.ts`:

Follow the pattern from the existing `apps/gateway/src/index.ts` but add StripeBillingProvider injection. The entry point must:
- Import `app` from `../../oss/apps/gateway/src/app`
- Import `handleScheduled` from `../../oss/apps/gateway/src/scheduled`
- Import `createCloudBindings` from `../../oss/apps/gateway/src/runtime/factory`
- Import `StripeBillingProvider` from `../../oss/apps/gateway/src/billing/stripe`
- Re-export `TokenCoordinator` from `../../oss/apps/gateway/src/durable-objects/token-coordinator`
- In `fetch` handler:
  1. Call `createCloudBindings(rawEnv)` to adapt Cloudflare bindings
  2. Extract `STRIPE_SECRET_KEY` from `rawEnv`
  3. Create `new StripeBillingProvider(stripeKey)` and assign to `adaptedEnv.BILLING_PROVIDER`
  4. Override `adaptedEnv.FEELR_CONFIG` to `{ runtime: 'cloud', billing: { enabled: true }, encryption: { enabled: true } }`
  5. Return `app.fetch(request, adaptedEnv, ctx)`
- In `scheduled` handler: wrap with `createCloudBindings` and delegate to `handleScheduled`

Use the exact code from the research document (Pattern 1) as the template.

**C. Create wrangler.cloud.toml** at `cloud/gateway/wrangler.cloud.toml`:

Copy the staging and production environment blocks from the CURRENT `apps/gateway/wrangler.toml` in the source repo (not the stripped public version). The config must have:
- Top-level: `name = "feelr-gateway"`, `main = "gateway-entry.ts"`, `compatibility_date = "2026-02-05"`, `keep_vars = true`
- Migrations: same as source (`tag = "v1"`, `new_sqlite_classes = ["TokenCoordinator"]`)
- Triggers: `crons = ["0 3 * * *"]`
- `[env.staging]`: Copy the COMPLETE staging section from the current wrangler.toml (routes, vars, kv_namespaces, d1_databases, durable_objects, unsafe.bindings)
- `[env.production]`: Copy the COMPLETE production section from the current wrangler.toml

IMPORTANT: The `main` field must point to `gateway-entry.ts` (not `src/index.ts`).


Note: Unlike the OSS tsconfig, this does NOT exclude `billing/stripe/**` because the cloud overlay needs those types.
