**Create `scripts/validate-connectors.mjs`:** A validation script that checks all connectors (or specific changed ones) for SDK compliance. The script runs both locally and in CI.

**CLI flags:**
- `--all`: Validate all connectors (default for local use)
- `--changed`: Validate only connectors with changes (for CI, uses `git diff` against `origin/main`)
- No flags defaults to `--all`

**Validation checks for each connector directory (excluding `_template`):**

1. **Package.json exists and is valid JSON**
   - Error: "Missing package.json in connectors/<name>/"

2. **SDK dependency check:** `dependencies` must include `@feelr/connector-sdk` and ONLY `@feelr/connector-sdk`
   - Error: "Disallowed runtime dependencies: <list>. Only @feelr/connector-sdk is allowed as a runtime dependency."

3. **Source file check:** `src/index.ts` must exist
   - Error: "Missing src/index.ts -- connector must have an entry point"

4. **Disallowed imports:** Scan all `.ts` files in `src/` for `node:` imports and `@cloudflare/` imports
   - Error: "Disallowed import in <file>: <import>. Connectors must use Web Standard APIs only."
   - Use regex: `/from\s+['"]node:/` and `/from\s+['"]@cloudflare\//`

5. **Test existence:** At least one `.test.ts` file must exist under `src/__tests__/`
   - Error: "No test files found in src/__tests__/. At least one .test.ts file is required."

**Output format:** For each connector, print a header line, then either "PASS" or a numbered list of errors. At the end, exit with code 0 if all pass, 1 if any fail.

Example output:
```
Validating connectors...

connectors/github: PASS
connectors/slack: PASS
connectors/stripe: PASS
connectors/discord: PASS

All 4 connectors passed validation.
```

Or on failure:
```
Validating connectors...

connectors/my-connector: FAIL
  1. Disallowed runtime dependencies: axios. Only @feelr/connector-sdk is allowed.
  2. Disallowed import in src/actions/list.ts: from 'node:fs'. Connectors must use Web Standard APIs only.

1 of 5 connectors failed validation.
```

**How to detect changed connectors (--changed):** Use `execSync('git diff --name-only origin/main...HEAD')`, extract unique connector names from paths matching `connectors/<name>/`. If no connectors changed, skip validation with a "No connector changes detected" message and exit 0.

**CRITICAL: Exclude `_template`** -- Check directory name, skip if starts with `_`.

**Update `.github/workflows/ci.yml`:** Add a `connector-validation` job after the existing `check` job:

```yaml
connector-validation:
  needs: check
  runs-on: ubuntu-latest
  timeout-minutes: 5
  steps:
    - uses: actions/checkout@v4
      with:
        fetch-depth: 0

    - uses: pnpm/action-setup@v4

    - uses: actions/setup-node@v4
      with:
        node-version: 20
        cache: "pnpm"

    - run: pnpm install --frozen-lockfile

    - name: Validate connector SDK compliance
      run: node scripts/validate-connectors.mjs --changed
```

Place this job AFTER `check` but BEFORE `gateway-preview` in the YAML. It depends on `check` (needs the check job to pass first). Use `timeout-minutes: 5` since validation is fast. Use `fetch-depth: 0` so `git diff origin/main...HEAD` works correctly.

The job runs on ALL PRs (not just connector PRs) because the `--changed` flag will early-exit with "No connector changes detected" if no connectors were modified. This is simpler than adding a path filter and avoids missing edge cases.
