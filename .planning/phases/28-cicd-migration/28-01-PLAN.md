  <action>
Clone the public repo to `/tmp/feelr-public` (shallow is fine for this):

```bash

```

Create `.github/workflows/sync.yml` in the clone with this exact content:

```yaml
# Cross-repo dispatch: notify cloud repo on merge to main (CICD-03)
# Requires CLOUD_REPO_PAT secret (fine-grained PAT scoped to feelr-cloud)
name: Sync to Cloud

on:
  push:
    branches: [main]

jobs:
  dispatch:
    runs-on: ubuntu-latest
    steps:
      - uses: peter-evans/repository-dispatch@v4
        with:
          token: ${{ secrets.CLOUD_REPO_PAT }}
          repository: progradetech/feelr-cloud
          event-type: oss-sync
          client-payload: '{"sha": "${{ github.sha }}", "ref": "${{ github.ref }}"}'
```

Key details:
- The `token` MUST be `CLOUD_REPO_PAT` (NOT `GITHUB_TOKEN` -- cross-repo dispatch requires a PAT)
- The `event-type: oss-sync` must match exactly what the cloud repo's sync.yml listens for
- The `client-payload` passes the triggering commit SHA for traceability in the cloud repo's sync commit message
- This workflow will NOT actually fire until `CLOUD_REPO_PAT` is set (Plan 03) -- the step will silently fail with an auth error

Commit and push to the public repo's main branch:

```bash
cd /tmp/feelr-public
git add .github/workflows/sync.yml
git commit -m "ci: add cross-repo sync dispatch to cloud repo"
git push origin main
```

Clean up: `rm -rf /tmp/feelr-public`
