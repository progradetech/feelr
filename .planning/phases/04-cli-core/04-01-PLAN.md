<task type="auto">
  <name>Task 1: Create /v1/tools discovery routes</name>
  <files>apps/gateway/src/routes/tools.ts</files>
  <action>
Create a new Hono router (`OpenAPIHono<AppEnv>`) with three GET routes for progressive connector discovery. Import `listConnectors` and `getConnector` from `../connectors/registry`, `wrapResponse` from `../lib/envelope`, and `FeelrError` from `../lib/errors`.

**Route 1: `GET /` (lists all connectors)**
- Call `listConnectors()` to get all registered ConnectorDefinitions
- Map each to: `{ name, display_name, version, auth_type, action_count: Object.keys(connector.actions).length }`
- Wrap in standard envelope via `wrapResponse()` with meta `{ connector: "gateway", action: "tools.list" }`

**Route 2: `GET /:connector` (lists actions for a connector)**
- Call `getConnector(connectorName)`
- If not found, throw FeelrError with code `CONNECTOR_NOT_FOUND`, status 404, hint `abort`
- Map `connector.actions` to array of: `{ name, description, returns }` (strip handler function)
- Return as `{ name: connector.name, display_name: connector.display_name, actions: [...] }`

**Route 3: `GET /:connector/:action` (full action schema)**
- Look up connector, then action within it
- If connector not found: 404 CONNECTOR_NOT_FOUND
- If action not found: 404 ACTION_NOT_FOUND
- Return: `{ name, description, params: action.params, returns }` (params already match ParamDefinition shape: name, type, required, description, default)

Export as `toolsRoutes`.

Note: These routes do NOT need their own API key middleware -- they will be mounted under `/v1` which already has `app.use('/v1/*', apiKeyMiddleware)` applied in app.ts.
