**cli/main.go:**
Thin entry point. Import `cli/cmd`. Call `cmd.Execute()`. On error, determine exit code from error type and call `os.Exit()`. Define a `CLIError` type with `ExitCode int` and `Message string` fields, plus `Error() string` method. Use `errors.As` to extract CLIError for exit code mapping.

Exit codes (per research): 0=success, 1=error, 2=auth required, 3=not found, 4=usage error.

**cli/cmd/root.go:**
Create root Cobra command:
- Use: "feelr"
- Short: "Agent-friendly API simplification layer"
- SilenceUsage: true, SilenceErrors: true (prevent Cobra from printing usage/errors to stdout, which corrupts JSON output)

Global persistent flags (available to all subcommands):
- `--profile` / `-p` (string, default "default") -- named config profile
- `--format` / `-f` (string, default "json") -- output format: json, minimal, table
- `--verbose` / `-v` (bool, default false) -- show full response envelope
- `--dry-run` (bool, default false) -- show HTTP request without executing
- `--color` (bool, default false) -- enable colored output (no color by default per user decision)
- `--gateway` (string, default "") -- override gateway URL

Export an `Execute() error` function that calls `rootCmd.Execute()`.

Do NOT use Viper global state. Create viper instances in config package instead.

**cli/internal/gateway/types.go:**
Go structs mirroring the gateway response envelope:

```go
// GatewayResponse is the standard envelope for successful responses
type GatewayResponse struct {
    OK   bool            `json:"ok"`
    Data json.RawMessage `json:"data"`
    Meta *ResponseMeta   `json:"meta,omitempty"`
}

// GatewayErrorResponse is the standard envelope for error responses
type GatewayErrorResponse struct {
    OK    bool          `json:"ok"`
    Error *ErrorDetail  `json:"error"`
}

// ErrorDetail contains structured error information
type ErrorDetail struct {
    Code    string `json:"code"`
    Message string `json:"message"`
    Detail  string `json:"detail,omitempty"`
    Hint    string `json:"hint"`
    Status  int    `json:"status"`
}

// ResponseMeta contains response metadata
type ResponseMeta struct {
    RequestID  string `json:"request_id"`
    Connector  string `json:"connector"`
    Action     string `json:"action"`
    DurationMs int    `json:"duration_ms"`
    Cursor     string `json:"cursor,omitempty"`
    HasMore    *bool  `json:"has_more,omitempty"`
}
```

Use `json.RawMessage` for `Data` so formatters can handle unwrapping vs verbose envelope without double-deserializing.

**cli/internal/config/config.go:**
Config struct with fields: `Gateway string`, `APIKey string`, `Profile string`.

`Load(profile string) (*Config, error)` function:
1. Create `viper.New()` instance (NOT global Viper -- per research pitfall)
2. SetConfigName("config"), SetConfigType("toml"), AddConfigPath("$HOME/.feelr"), AddConfigPath(".")
3. SetEnvPrefix("FEELR"), AutomaticEnv()
4. ReadInConfig() -- ignore ConfigFileNotFoundError (allow env-only usage)
5. Read `profile + ".gateway"` and `profile + ".api_key"` from Viper
6. Env var `FEELR_API_KEY` overrides config file api_key
7. Env var `FEELR_GATEWAY` overrides config file gateway
8. If gateway is still empty, default to "https://api.feelr.dev"
9. Return Config struct

Also provide `ConfigPath() string` that returns the expected config file path (`~/.feelr/config.toml`).

**cli/internal/client/client.go:**
`GatewayClient` struct with `httpClient *http.Client`, `baseURL string`, `apiKey string`.

`NewGatewayClient(baseURL, apiKey string) *GatewayClient`:
- Create http.Client with 30-second timeout (per research pitfall #3)
- Trim trailing slash from baseURL

`(c *GatewayClient) Run(connector, action string, params map[string]string) (*gateway.GatewayResponse, error)`:
- POST to `{baseURL}/v1/{connector}/{action}`
- Set Content-Type: application/json, X-Feelr-Key: {apiKey}
- Marshal params as JSON body
- Parse response: try GatewayResponse first; if ok=false, parse as GatewayErrorResponse and return as CLIError with appropriate exit code (map hint "auth" -> exit 2, otherwise exit 1)

`(c *GatewayClient) GetTools(path string) (*gateway.GatewayResponse, error)`:
- GET to `{baseURL}/v1/tools{path}` (path can be "", "/github", "/github/issues.list")
- Same auth header, parse response

`(c *GatewayClient) GetStatus() (*gateway.GatewayResponse, error)`:
- GET to `{baseURL}/status`
- Same auth header, parse response

`(c *GatewayClient) BuildRequest(method, path string, body []byte) (*http.Request, error)`:
- Build request without executing (for --dry-run support)
- Set all headers

**cli/internal/output/formatter.go:**
```go
type Formatter interface {
    FormatData(data json.RawMessage, meta *gateway.ResponseMeta) error
    FormatError(err error) error
}

func NewFormatter(format string, verbose bool, color bool, w io.Writer, errW io.Writer) Formatter
```
Factory returns JSONFormatter (default), MinimalFormatter, or TableFormatter based on format string.

**cli/internal/output/json.go:**
JSONFormatter struct with `verbose bool`, `w io.Writer`.
- FormatData: If verbose=false, print just the raw `data` field (unwrapped -- per user decision). If verbose=true, print the full `{ ok, data, meta }` envelope.
- Both modes: pretty-print with json.MarshalIndent (2-space indent) to stdout
- FormatError: Print `{"error": "message"}` to errW (stderr)

**cli/internal/output/minimal.go:**
MinimalFormatter struct with `w io.Writer`.
- FormatData: Unmarshal data. If array: pipe-delimited rows (extract values, join with `|`). If object: key=value pairs on one line.
- Per research: `42|open|Fix login bug|alice` for lists, `number=42 state=open title="Fix login bug"` for singles.
- Quote values containing spaces.
- FormatError: Single line `error: {message}` to errW

**cli/internal/output/table.go:**
TableFormatter struct with `color bool`, `w io.Writer`.
- FormatData: Unmarshal data. If array of objects: extract keys from first item as headers, render with text/tabwriter. If single object: two-column KEY/VALUE table.
- Use tabwriter with minwidth=0, tabwidth=4, padding=2, padchar=' '
- If color=true, bold headers (ANSI escape codes). Otherwise plain text.
- FormatError: Print error to errW

All formatters write data to `w` (stdout) and errors to `errW` (stderr) per the stream separation decision.
