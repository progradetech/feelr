**use-walkthrough.ts** ('use client'):
- Export `useWalkthrough(onComplete: () => void)` hook.
- State: `state: 'idle' | 'running' | 'complete'`, `stepIndex: number` (starts at -1), `stepDone: boolean`.
- Use `useRef` for `onComplete` callback (stable reference, avoids stale closure).
- `start()` function: sets state to 'running', stepIndex to 0, stepDone to false.
- Effect 1 -- step advancement: When `state === 'running' && stepDone`, advance to next step. If `nextIndex >= WALKTHROUGH_STEPS.length`, set state to 'complete' and call `onCompleteRef.current()`. Otherwise, set stepIndex to nextIndex and stepDone to false.
- Effect 2 -- pause handler: When `state === 'running'` and current step is `type === 'pause'`, set a timeout for `step.duration` ms, then call `setStepDone(true)`. Clean up timeout on unmount.
- Return: `{ state, currentStep, completedSteps, stepIndex, start, markStepDone: () => setStepDone(true) }`.
- `completedSteps` = `WALKTHROUGH_STEPS.slice(0, stepIndex)` (all steps before current).
- `currentStep` = `stepIndex >= 0 ? WALKTHROUGH_STEPS[stepIndex] : null`.

**terminal-demo.tsx** ('use client'):
- Export `TerminalDemo` component (no props).
- Import: `useWalkthrough`, `useReducedMotion`, `useDemo` (from `@/lib/demo-context`), `useRouter` (from `next/navigation`), `TerminalShell`, `TypingLine`, `OutputBlock`, `WALKTHROUGH_STEPS`, `Play` icon from `lucide-react`.
- Setup:
  - `const { enterDemo } = useDemo();`
  - `const router = useRouter();`
  - `const reducedMotion = useReducedMotion();`
  - `const handleComplete = useCallback(() => { enterDemo(); router.push('/overview'); }, [enterDemo, router]);`
  - `const { state, currentStep, completedSteps, stepIndex, start, markStepDone } = useWalkthrough(handleComplete);`

- **Reduced motion handling:** If `reducedMotion && state === 'idle'`, when user clicks "Try Demo", instead of animating, show all steps in completed state instantly, wait 1.5 seconds, then call `handleComplete()`. Implement by having a `handleStart` function that checks `reducedMotion`: if true, show static completed terminal + transition after brief delay; if false, call `start()`.

- **Rendering logic:**
  - Outer wrapper: `<section className="px-4 py-16 md:px-6">` with `<div className="mx-auto max-w-2xl">`.
  - Section heading: `<h2>` with "See It in Action" text, centered, `font-heading text-center text-2xl font-bold text-white md:text-3xl mb-8`.
  - `<TerminalShell title="feelr">` wrapping the terminal content.
  - Inside TerminalShell, render in this order:
    1. **Completed steps:** Iterate over `completedSteps`. For each:
       - If `type === 'typing'`: render a static `<div>` with prompt + full text (no animation, already done).
       - If `type === 'output'`: render a static `<div>` with all lines (no animation, already done).
       - If `type === 'pause'`: render nothing.
    2. **Current step** (only when `state === 'running'` and `currentStep` exists):
       - If `type === 'typing'`: render `<TypingLine prompt={currentStep.prompt} text={currentStep.text} speed={currentStep.duration} onComplete={markStepDone} />`.
       - If `type === 'output'`: render `<OutputBlock lines={currentStep.lines} onComplete={markStepDone} />`.
       - If `type === 'pause'`: render nothing (handled by hook).
  - **Idle state:** When `state === 'idle'`, show a placeholder message inside the terminal like `<div className="text-zinc-500">Click "Try Demo" to watch Feelr in action...</div>`.
  - **Complete state:** When `state === 'complete'`, show all steps rendered statically (same as completed steps rendering).

  - **CTA Button** (below the TerminalShell, NOT inside it):
    - When `state === 'idle'`: Show "Try Demo" button with `Play` icon. Styling: `mt-6 flex justify-center`. Button: `inline-flex items-center gap-2 rounded-lg bg-emerald-600 px-6 py-3 font-medium text-white transition-colors hover:bg-emerald-500`.
    - When `state === 'running'`: Show "Watching..." text, button disabled, `bg-zinc-700 cursor-not-allowed` styling.
    - When `state === 'complete'`: Show "Explore Dashboard" button with arrow icon. Same emerald styling. On click: call `handleComplete()` (in case the auto-transition already fired, this is a fallback).

- **Static completed terminal for reduced motion:**
  When `reducedMotion` is true and user clicks "Try Demo", immediately render all WALKTHROUGH_STEPS as static content (no animation), show "Entering demo..." text, then after 1500ms call `handleComplete()`. Manage this with a local `reducedMotionActive` state boolean.
