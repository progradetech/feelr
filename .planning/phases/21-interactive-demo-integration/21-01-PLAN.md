**typing-line.tsx** ('use client'):
- Export `TypingLine` component with props: `prompt?: string`, `text: string`, `speed?: number` (default 60), `onComplete?: () => void`, `className?: string`.
- Uses `useState` for `displayed` string, `useRef` for character index counter, and `useRef` for `onComplete` callback (to avoid stale closure -- per research pitfall #1).
- On mount (or when `text` changes): reset index to 0 and `displayed` to '', start `setInterval` at `speed` ms.
- Each interval tick: increment index, `setDisplayed(text.slice(0, index))`. When index > text.length: `clearInterval`, call `onCompleteRef.current?.()`.
- Cleanup: always `clearInterval` on unmount/re-render.
- Render: `<div className={className}><span className="text-emerald-400">{prompt}</span><span>{displayed}</span>{cursor}</div>`
- Cursor: only show while typing (index < text.length). Use `<span className="inline-block w-2 h-4 bg-zinc-300 ml-0.5 align-middle animate-terminal-cursor" />`.

**output-block.tsx** ('use client'):
- Export `OutputBlock` component with props: `lines: string[]`, `onComplete?: () => void`, `className?: string`.
- Uses `useRef` for `onComplete` callback (stable reference pattern).
- On mount: set a timeout for 300ms (the fade-in duration), then call `onCompleteRef.current?.()`.
- Cleanup: clear timeout on unmount.
- Render: `<div className={cn("animate-terminal-fade-in opacity-0", className)}>{lines.map((line, i) => <div key={i}>{line || '\u00A0'}</div>)}</div>`
- Use `opacity-0` as initial state so the `animate-terminal-fade-in` animation starts from 0 and fills forward to 1.
- Do NOT import cn from any utility -- just use template literal string concatenation since there is no cn utility in this project.

**terminal-shell.tsx** ('use client'):
- Export `TerminalShell` component with props: `title?: string` (default 'Terminal'), `children: React.ReactNode`, `className?: string`.
- Render a macOS-style terminal chrome:
  - Outer div: `overflow-hidden rounded-xl border border-zinc-800 bg-zinc-950 shadow-2xl ${className}`
  - Title bar: `flex items-center gap-2 border-b border-zinc-800 px-4 py-3`
  - Traffic lights: three `h-3 w-3 rounded-full` divs with `bg-red-500`, `bg-yellow-500`, `bg-green-500`
  - Title text: `<span className="ml-2 text-xs text-zinc-500">{title}</span>`
  - Content area: `<div className="overflow-y-auto p-4 font-mono text-sm leading-relaxed text-zinc-300">{children}</div>`
- Use `<div>` for content area (not `<pre><code>`) since child components are React elements, not raw text.
