**Part A: Create `apps/gateway/src/billing/middleware.ts`**

Create a new middleware that delegates to BillingProvider. This middleware must preserve the EXACT same behavior as the current `planEnforcer()` in `plan-enforcer.ts`:

1. Import `createMiddleware` from `hono/factory`, `FeelrError` from `../lib/errors`, `NoopBillingProvider` and `BillingProvider` (type) from `./provider`, `CustomerBilling` (type) from `./types`.

2. Export `billingMiddleware()` factory function returning `createMiddleware<AppEnv>()`:
   - First check: if `!c.env.FEELR_CONFIG?.billing?.enabled`, call `return next()` -- preserves the self-hosted no-op path
   - Get the provider: `const provider: BillingProvider = (c.env as any).BILLING_PROVIDER ?? new NoopBillingProvider()` -- use `(c.env as any)` for now since BILLING_PROVIDER is not yet on AppEnv (that happens in Plan 02)
   - Second check: if `!c.get('apiKeyRecord')`, call `return next()` -- preserves the no-auth fallback
   - Get `apiKeyShort` from `apiKeyRecord.shortToken`
   - Call `provider.enforceQuota(apiKeyShort, async (key) => c.env.AUTH_KV.get<CustomerBilling>(key, 'json'))`
   - If `!result.allowed`, throw `new FeelrError('PLAN_QUOTA_EXCEEDED', { message: \`Monthly API quota exceeded for ${result.plan} plan (${result.limit?.toLocaleString()} calls/month). Upgrade your plan for higher limits.\`, hint: 'abort', status: 402 })`
   - Call `await next()`
   - After next: get billing state from KV, get customerId from billing or apiKeyRecord
   - Call `c.executionCtx.waitUntil(provider.recordUsage(...).catch(() => {}))` for best-effort recording

CRITICAL: The error message format, status code (402), error code (PLAN_QUOTA_EXCEEDED), and the waitUntil pattern MUST match the current plan-enforcer.ts exactly. The behavior must be identical.
