Export all three as named exports.

Update `apps/dashboard/src/app/globals.css` to add `@theme inline` block AFTER the existing `@import "tailwindcss"` line. Map font CSS variables to Tailwind utilities:

```css
@import "tailwindcss";

@theme inline {
  --font-sans: var(--font-inter);
  --font-heading: var(--font-space-grotesk);
  --font-mono: var(--font-jetbrains-mono);
}
```

This makes `font-sans` (body), `font-heading` (headings), and `font-mono` (code) available as Tailwind classes. MUST use `@theme inline` (not `@theme` without inline) because next/font injects CSS variables at runtime via class names on html element, and Tailwind needs `inline` to keep var() references in output CSS rather than trying to resolve at build time.
