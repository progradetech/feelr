    In `apps/docs/app/layout.tsx`, update the Navbar `logo` prop (line 26) from `<b>Feelr</b>` to include the logomark image alongside the bold text.

    Replace:
    ```tsx
    logo={<b>Feelr</b>}
    ```

    With:
    ```tsx
    logo={
      <span style={{ display: 'flex', alignItems: 'center', gap: '0.5rem' }}>
        <img src="/feelr-logomark.svg" alt="Feelr" width={24} height={24} />
        <b>Feelr</b>
      </span>
    }
    ```

    Use inline styles (not Tailwind) because:
    - The docs layout is a Server Component inside the Nextra layout system.
    - Inline styles avoid any class name resolution issues with the Nextra CSS pipeline.
    - The Nextra Navbar wraps the logo in a flex container with `items-center`, so vertical alignment is already handled by the parent.

    The logomark SVG was already copied to `apps/docs/public/` in Task 1.

    Note on light mode: The logomark uses gradient strokes (#E85D3A to #C4B5FD) which are visible on both light and dark backgrounds. The tiny white inner circles on antenna tips may be less visible on pure white backgrounds, but the overall logo remains recognizable. No CSS filter or variant SVG is needed.
