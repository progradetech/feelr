    - `wrapResponse<T>(options: { data: T, meta: ResponseMeta }): FeelrResponse<T>` -- wraps successful data in { ok: true, data, meta }
    - `wrapError(options: { code, message, hint, status, detail? }): FeelrErrorResponse` -- wraps error in { ok: false, error: { ... } }

    - Phase 1: NO validation -- just extraction. Auth comes in Phase 2.

    - Export ErrorHandler<AppEnv> function
    - Handle FeelrError: return { ok: false, error: { code, message, detail, hint, status } } with correct HTTP status
    - Handle Hono HTTPException: map to INTERNAL_ERROR with retry hint
    - Handle unknown errors: log to console.error, return INTERNAL_ERROR with 500 status and retry hint
    - Per locked decision: three hints only (retry, auth, abort)
    - Per locked decision: error includes Feelr-authored message + upstream detail

    **connectors/registry.ts -- Connector lookup (GATE-01):**
    - Private `Map<string, ConnectorDefinition>` for storage
    - `registerConnector(connector: ConnectorDefinition): void` -- adds to map by connector.name
    - `getConnector(name: string): ConnectorDefinition | undefined` -- looks up by name
    - `listConnectors(): ConnectorDefinition[]` -- returns all registered connectors as array
    - Import ConnectorDefinition from @feelr/connector-sdk

    **connectors/mock.ts -- Mock connector for pipeline testing:**
    - Implements ConnectorDefinition from @feelr/connector-sdk
    - name: 'mock', display_name: 'Mock Connector', version: '1.0.0', auth_type: 'none'
    - Action 'echo' (returns: 'single'):
      - Params: message (string, optional, default 'hello')
      - Handler: returns { data: { message, timestamp (ISO 8601 UTC) }, raw: { original_params: ctx.params } }
      - Description: agent-optimized, 50-100 tokens
    - Action 'items.list' (returns: 'list'):
      - Params: count (number, optional, default 10), cursor (string, optional)
      - Handler: generates array of { id, name, created_at (ISO 8601 UTC) } items
      - Returns meta with has_more: true and cursor: 'mock_cursor_next'
      - Description: agent-optimized, 50-100 tokens
    - Action 'error.throw' (returns: 'single') -- for testing error pipeline:
      - Params: code (string, optional, default 'UPSTREAM_ERROR'), status (number, optional, default 502)
      - Handler: throws FeelrError with the specified code and status, hint 'retry', detail 'Simulated upstream error'
      - Description: agent-optimized, explains it's for testing error handling

    **routes/v1.ts -- Main dispatch route (GATE-01, GATE-02, GATE-04):**
    - Create OpenAPIHono<AppEnv> instance
    - Register mock connector on module load: import mockConnector, call registerConnector(mockConnector)
    - Route handler `v1.all('/:connector/:action', handler)`:
      1. Extract connectorName and actionName from params
      2. Get requestId from context
      3. Look up connector via getConnector(connectorName) -- throw FeelrError CONNECTOR_NOT_FOUND (404, abort) if not found
      4. Look up action in connector.actions[actionName] -- throw FeelrError ACTION_NOT_FOUND (404, abort) if not found
      5. Extract params: GET -> from URL searchParams, POST/PUT/DELETE -> from JSON body (catch parse errors gracefully)
      6. Remove system params (key, raw, cursor) from action params
      7. Record start time
      8. Call action.handler({ params: actionParams, fetch: fetch })
      9. Calculate duration_ms
      10. If ?raw=true AND result.raw exists, return c.json(result.raw) directly (no envelope per locked decision)
      11. Otherwise, return c.json(wrapResponse({ data: result.data, meta: { request_id, connector, action, duration_ms, ...pagination from result.meta } }))
    - Export as v1Routes

    After all files are created, verify the full pipeline works by running `wrangler dev` briefly or by running `pnpm turbo typecheck` to confirm everything compiles.

    Per research recommendation for URL action pattern: dot notation in path (/v1/github/issues.list). The :action param captures the full dot-notation string.
    Per research recommendation for HTTP methods: app.all() accepts any method (RPC-style gateway).
    Per research recommendation for meta contents: request_id, connector, action, duration_ms, plus optional cursor/has_more.
    Per research recommendation for data shape: array for list actions, object for single actions (determined by action.returns).
    Per research recommendation for timestamps: ISO 8601 with UTC (Z suffix).
