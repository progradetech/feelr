Create `cli/internal/chain/types.go` with the following Go structs matching the YAML/JSON schema from research:

```go
package chain

// Chain represents a complete chain definition loaded from YAML or JSON.
type Chain struct {
    Name        string      `yaml:"name" json:"name"`
    Description string      `yaml:"description" json:"description"`
    Version     string      `yaml:"version" json:"version"`
    Params      []Param     `yaml:"params" json:"params"`
    Retry       RetryPolicy `yaml:"retry" json:"retry"`
    Steps       []Step      `yaml:"steps" json:"steps"`
}

// Param defines a runtime parameter that users provide when executing a chain.
type Param struct {
    Name        string `yaml:"name" json:"name"`
    Type        string `yaml:"type" json:"type"`           // "string", "number", "boolean"
    Required    bool   `yaml:"required" json:"required"`
    Description string `yaml:"description" json:"description"`
    Default     string `yaml:"default,omitempty" json:"default,omitempty"`
}

// Step defines a single action in the chain execution sequence.
type Step struct {
    ID      string            `yaml:"id" json:"id"`
    Uses    string            `yaml:"uses" json:"uses"`        // "connector/action" format
    With    map[string]string `yaml:"with" json:"with"`        // param map with ${{ }} interpolation
    If      string            `yaml:"if,omitempty" json:"if,omitempty"` // conditional expression
    Timeout int               `yaml:"timeout,omitempty" json:"timeout,omitempty"` // seconds, 0=default
}

// RetryPolicy defines the global retry behavior for chain steps.
type RetryPolicy struct {
    MaxAttempts  int `yaml:"max_attempts" json:"max_attempts"`
    DelaySeconds int `yaml:"delay_seconds" json:"delay_seconds"`
}
```

Key decisions:
- Combined `uses` field with "connector/action" format (e.g., "github/issues.create") -- matches GitHub Actions pattern
- `With` values are strings that may contain `${{ }}` interpolation templates
- `Param.Default` is string (will be coerced at runtime based on Type)
- RetryPolicy defaults: max_attempts=1, delay_seconds=0 (no retry) when omitted

Also add constants:
```go
const (
    MaxSteps     = 10
    MaxChainName = 64
)
```

Create `cli/internal/chain/loader.go` with a `LoadChain` function that:

1. **File loading**: Reads file from disk, detects format by extension (.yaml/.yml -> YAML, .json -> JSON)
2. **Parsing**: Uses `go.yaml.in/yaml/v3` for YAML, `encoding/json` for JSON (yaml/v3 is already an indirect dep in go.mod)
3. **Validation** via `ValidateChain(chain *Chain) error`:
   - Name is non-empty and <= MaxChainName characters
   - At least 1 step, at most MaxSteps (10) steps
   - No duplicate step IDs
   - Each step has non-empty `id` and `uses` field
   - `uses` field contains exactly one `/` separator (connector/action format)
   - All param names are non-empty, type is one of "string", "number", "boolean"
   - Required params without defaults are flagged
   - Step `if` expressions referencing `steps.X` must reference step IDs that appear earlier in the list (no forward references)
   - RetryPolicy: max_attempts must be >= 1 if specified, delay_seconds >= 0

4. **Default application**: If retry is zero-valued, set max_attempts=1, delay_seconds=0

Function signatures:
```go
func LoadChain(path string) (*Chain, error)
func LoadChainFromBytes(data []byte, format string) (*Chain, error)
func ValidateChain(chain *Chain) error
```

`LoadChainFromBytes` accepts "yaml" or "json" format string -- used by gateway upload path.

Errors should be descriptive: include step ID and field name in validation errors.

Create `cli/internal/chain/loader_test.go` testing:
- Valid YAML chain loads correctly with all fields populated

- Validation: too many steps (11) -> error
- Validation: duplicate step IDs -> error
- Validation: invalid uses format (no slash) -> error
- Validation: forward reference in if expression -> error
- Validation: empty name -> error
- Default retry policy applied when omitted
