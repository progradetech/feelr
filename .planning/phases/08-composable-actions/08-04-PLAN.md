```go
package chain

// BuiltinChains lists the names of all built-in chains that ship with Feelr.
// The actual YAML definitions are embedded at build time or loaded from the
// chains/ directory relative to the binary.
var BuiltinChains = []string{
    "github-slack-issue-notify",
    "github-discord-pr-notify",
    "stripe-slack-payment-alert",
    "github-stripe-customer-issue",
    "slack-discord-cross-post",
    "github-slack-pr-review",

// ResolveChain resolves a chain name or file path to a loaded Chain.
// Resolution order:
// 1. If name ends in .yaml, .yml, or .json -> load as file path
// 2. Check built-in chains directory (chains/<name>.yaml)
// 3. Check current directory (./<name>.yaml)
// 4. Return error if not found
func ResolveChain(nameOrPath string) (*Chain, error)
```

Implementation of ResolveChain:
- Check if nameOrPath has a file extension (.yaml/.yml/.json) -> LoadChain(nameOrPath) directly
- Otherwise, search for the chain file:
  - Look for an embedded built-in (for now, try `chains/<name>.yaml` relative to executable dir using os.Executable())
  - Try `./<name>.yaml` and `./<name>.json` in current directory
  - Return descriptive error: `chain "X" not found. Use "feelr chain list" to see available chains.`

1. **chain_run.go** -- `feelr chain run <name-or-file> [key=value...]`:
   - Parse key=value args (same pattern as run.go) into params map
   - Load config, create GatewayClient (same pattern as run.go)
   - Resolve chain via `chain.ResolveChain(args[0])`
   - Create ActionRunner that wraps gwClient.Run:
     ```go
     runner := func(connector, action string, params map[string]string) (map[string]interface{}, error) {
         resp, err := gwClient.Run(connector, action, params, "")
         if err != nil {
             return nil, err
         }
         var data map[string]interface{}
         if err := json.Unmarshal(resp.Data, &data); err != nil {
             // Try as array
             var arr []interface{}
             if err2 := json.Unmarshal(resp.Data, &arr); err2 != nil {
                 return nil, fmt.Errorf("parsing step output: %w", err)
             }
             return map[string]interface{}{"items": arr}, nil
         }
         return data, nil
     }
     ```
   - Execute chain via `chain.Execute(opts)` with OnStep callback:
     - If --verbose: print step progress to stderr (`fmt.Fprintf(os.Stderr, "Step %s: %s\n", stepID, status)`)
   - On success: output final step's data to stdout via formatter (same as run.go)
   - On failure: output error to stderr with which step failed
   - Flags: inherit global flags (--verbose, --format, --profile, --gateway)
   - Increase HTTP client timeout to 90 seconds for chain execution (chains take longer)
