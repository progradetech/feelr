Create `cli/internal/chain/condition.go` implementing condition evaluation. Do NOT use expr-lang/expr -- implement a lightweight evaluator in pure Go to avoid the dependency. The conditions in chain definitions are simple comparisons, not arbitrary expressions.

**Function signature:**
```go
func EvalCondition(expr string, ctx *ResolveContext) (bool, error)
```

**Process:**
1. First resolve all `${{ }}` templates in the expression string using `ResolveTemplate`
2. Parse the resolved string as a boolean expression

**Supported expressions after template resolution:**
- Simple truthy: `"some_value"` -> true (non-empty = true, empty/"0"/"false" = false)
- Comparison: `"42" > "0"` (numeric comparison when both sides parse as numbers)
- String comparison: `"hello" == "hello"`
- Contains: `"hello world" contains "world"`
- Exists: `exists "some_value"` (non-empty check, shorthand for truthy)
- Boolean combinators: `expr1 && expr2`, `expr1 || expr2`

**Parser implementation:**
1. Split on ` || ` first (lowest precedence) to get OR groups
2. Within each OR group, split on ` && ` to get AND terms
3. Each term is a single comparison: `left operator right` or `exists value` or just a truthy value
4. Operators: `==`, `!=`, `>`, `<`, `>=`, `<=`, `contains`, `exists`
5. For numeric comparisons (>, <, >=, <=): try to parse both sides as float64. If either fails, do string comparison
6. `contains`: left string contains right string (case-sensitive)
7. `exists`: the value is non-empty

**Edge cases:**
- Empty expression -> true (unconditional step)
- Quoted strings in fallback values from `??` should already be resolved by ResolveTemplate

**Tests in condition_test.go:**
- `EvalCondition("42 > 0", ctx)` -> true
- `EvalCondition("hello == hello", ctx)` -> true
- `EvalCondition("hello != world", ctx)` -> true
- `EvalCondition("hello world contains world", ctx)` -> true
- `EvalCondition("exists somevalue", ctx)` -> true
- `EvalCondition("exists ", ctx)` -> false (empty after exists)
- `EvalCondition("42 > 0 && hello == hello", ctx)` -> true
- `EvalCondition("42 > 100 || hello == hello", ctx)` -> true
- `EvalCondition("42 > 100 && hello == hello", ctx)` -> false
- `EvalCondition("5 <= 5", ctx)` -> true
- `EvalCondition("5 >= 6", ctx)` -> false
- `EvalCondition("", ctx)` -> true (empty = unconditional)
- Test with `${{ }}` expressions: `EvalCondition("${{ steps.x.count }} > 0", ctx)` -> resolves then evaluates

Create `cli/internal/chain/executor.go` implementing the chain execution engine.

**Key types:**

```go
// ActionRunner is the function signature for executing a single connector action.
// The executor calls this for each step. CLI provides a runner that calls the gateway;
// gateway provides a runner that calls action.handler() directly.
type ActionRunner func(connector, action string, params map[string]string) (map[string]interface{}, error)

// StepResult holds the output of a single step execution.
type StepResult struct {
    StepID   string
    Output   map[string]interface{}
    Skipped  bool
    Error    error
    Duration time.Duration
}

// ChainResult holds the complete chain execution result.
type ChainResult struct {
    Steps   []StepResult
    Success bool
}

// ExecuteOpts configures chain execution.
type ExecuteOpts struct {
    Chain      *Chain
    Params     map[string]string
    Runner     ActionRunner
    OnStep     func(stepID string, status string) // callback for progress reporting
    Verbose    bool
}
```

**Execute function:**

```go
func Execute(opts ExecuteOpts) (*ChainResult, error)
```

**Logic:**
1. Validate that all required chain params are provided (check opts.Params against chain.Params where required=true)
2. Apply param defaults for missing optional params
3. Initialize ResolveContext with params and empty steps map
4. For each step in chain.Steps:
   a. If step.If is non-empty, evaluate condition via EvalCondition(step.If, ctx)
      - If false: record StepResult{Skipped: true}, set steps[stepID] = nil in context, continue
   b. Resolve all step.With values using ResolveTemplate(value, ctx) -> resolved params map
   c. Parse step.Uses into connector and action (split on `/`)
   d. Execute with retry: loop up to chain.Retry.MaxAttempts times
      - Call opts.Runner(connector, action, resolvedParams)
      - On success: break loop
      - On error: if attempts remaining, sleep chain.Retry.DelaySeconds, retry
      - On final failure: record error, halt chain (return partial ChainResult with Success=false)
   e. Store step output in ctx.Steps[step.ID] for subsequent steps
   f. Record StepResult with output, duration
   g. Call opts.OnStep(step.ID, "complete") if callback set
5. Return ChainResult with all step results, Success=true
