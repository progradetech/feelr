    1. Create `apps/dashboard/src/lib/hooks/use-usage.ts`:
    - 'use client'.
    - Export interface `UsageFilters`:
      ```typescript
      interface UsageFilters {
        key?: string;       // api_key_short to filter by
        connector?: string; // connector name to filter by
        window: 'hour' | 'day' | 'month';
      }
      ```
    - Export `useUsage(filters: UsageFilters)` hook.
    - Build query params string from filters. IMPORTANT: Use descriptive SWR keys that include all filter values to avoid cache collisions: `usage-${filters.window}-${filters.key || 'all'}-${filters.connector || 'all'}`.
    - Fetch: `gatewayFetch<UsageResponse>('/internal/usage?' + params.toString())`.
    - Also export `useAvailableKeys()`: SWR hook that fetches `/admin/keys` to populate the key filter dropdown. Returns `ApiKey[]`.
    - Also export `useAvailableConnectors()`: returns the static list `['github', 'slack', 'stripe', 'discord']` (no fetch needed, connectors are known).

    2. Create `apps/dashboard/src/components/usage-chart.tsx`:
    - 'use client' component.
    - Props: `data: UsageBucket[]`, `window: string`.
    - Uses Recharts: `ResponsiveContainer` (width 100%, height 350), `AreaChart`.
    - Two Area series on the same chart:
      a. `total_requests`: blue fill (#3b82f6 stroke, #3b82f680 fill), primary area.
      b. `error_count`: red fill (#ef4444 stroke, #ef444440 fill), overlaid area (shows errors as portion of total).
    - XAxis: `dataKey="time_bucket"`, formatted based on window:
      - hour: show "HH:mm" (e.g., "14:00")
      - day: show "MMM dd" (e.g., "Jan 15")
      - month: show "MMM yyyy" (e.g., "Jan 2026")
    - Use date-fns `format` and `parseISO` for formatting.
    - YAxis: auto-scaled, label "Requests".
    - Tooltip: shows time_bucket, total_requests, error_count, avg_duration_ms.
    - CartesianGrid with dashed lines in zinc-800 for dark theme.
    - Empty state: centered "No usage data for this time range" message.

    3. Create `apps/dashboard/src/components/usage-breakdown.tsx`:
    - 'use client' component.
    - Props: `data: UsageBucket[]`.
    - Summary stats displayed as a row of stat cards below the chart:
      a. "Total Requests": sum of all total_requests.
      b. "Error Rate": (sum of error_count / sum of total_requests * 100).toFixed(1) + '%'. Show in red if > 5%.
      c. "Avg Latency": average of avg_duration_ms across all buckets, displayed as "Xms".
    - Use shadcn Card components, compact layout.
