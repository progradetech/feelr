<task type="auto">
  <name>Task 2: /internal/* routes for dashboard data aggregation</name>
  <files>

  <action>
    1. Create `apps/gateway/src/routes/internal.ts`:
    - Import Hono, AppEnv type, adminAuthMiddleware.
    - Create a new Hono instance. Apply adminAuthMiddleware to all routes (`internal.use('*', adminAuthMiddleware)`).

    2. Implement `GET /overview` route:
    - Runs three queries in parallel (Promise.all):
      a. `c.env.AUTH_KV.list({ prefix: 'apikey:' })` to count total keys.
      b. Call `listCredentials(c.env.AUTH_KV)` (import from auth/credentials) to get connected services count.
      c. Query USAGE_DB for recent usage summary: total requests in last 24h, and a simple hourly breakdown (last 24 data points) for the sparkline. SQL: `SELECT strftime('%Y-%m-%dT%H:00:00Z', timestamp) as hour, COUNT(*) as count FROM usage WHERE timestamp >= datetime('now', '-24 hours') GROUP BY hour ORDER BY hour`. Handle case where USAGE_DB may not have the table yet (catch D1 errors, return empty array).
    - Return standard envelope: `{ ok: true, data: { total_keys, connected_services, recent_usage: { total_24h, hourly: [{hour, count}] } } }`.

    3. Implement `GET /usage` route:
    - Accept query params: `key` (api_key_short filter), `connector` (connector filter), `window` (hour|day|month, default 'day'), `from` (ISO timestamp), `to` (ISO timestamp).
    - Build a SQL query against the usage table that:
      a. Groups by time bucket using strftime: '%Y-%m-%dT%H:00:00Z' for hour, '%Y-%m-%d' for day, '%Y-%m' for month.
      b. Applies WHERE clauses for key and connector if provided.
      c. Applies time range via `timestamp >= ? AND timestamp <= ?` if from/to provided. Default: last 24 hours for 'hour', last 30 days for 'day', last 12 months for 'month'.
      d. Returns: time_bucket, total_requests (COUNT(*)), error_count (COUNT where status_code >= 400), avg_duration_ms (AVG(duration_ms)).
    - Return standard envelope: `{ ok: true, data: { window, buckets: [{time_bucket, total_requests, error_count, avg_duration_ms}], filters: {key, connector} } }`.
    - Handle D1 table-not-found errors gracefully (return empty buckets array).

    4. In `apps/gateway/src/app.ts`:
    - Import `internalRoutes` from `./routes/internal`.
    - Mount with `app.route('/internal', internalRoutes)` BEFORE the 404 handler. Place it after the admin routes mount and before the v1 tools mount (or alongside the admin routes -- the exact position does not matter as long as it is before the 404 handler).

    5. Export `internalRoutes` from internal.ts.
