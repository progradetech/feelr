  <name>Task 1: Add web manifest and update metadata for both apps</name>
  <files>

  <action>
    **Dashboard manifest.ts** — Create `apps/dashboard/src/app/manifest.ts`:
    ```typescript
    import type { MetadataRoute } from 'next'

    export default function manifest(): MetadataRoute.Manifest {
      return {
        name: 'Feelr',
        short_name: 'Feelr',
        description: 'Agent-friendly API simplification. One CLI, one API key, every integration.',
        start_url: '/',
        display: 'standalone',
        background_color: '#09090b',
        theme_color: '#E85D3A',
        icons: [
          { src: '/icon-192.png', sizes: '192x192', type: 'image/png' },
          { src: '/icon-512.png', sizes: '512x512', type: 'image/png' },
        ],
      }
    }
    ```

    **Dashboard layout.tsx** — Update `apps/dashboard/src/app/layout.tsx`:
    1. Add `import type { Viewport } from 'next'` alongside existing `Metadata` import
    2. Change `metadataBase` from hardcoded `new URL('https://app.feelr.dev')` to:
       ```typescript
       metadataBase: new URL(process.env.NEXT_PUBLIC_SITE_URL ?? 'http://localhost:3000'),
       ```
    3. Add viewport export AFTER the metadata export:
       ```typescript
       export const viewport: Viewport = {
         themeColor: '#E85D3A',
       }
       ```
    4. Do NOT touch anything else in layout.tsx (keep all existing imports, body classes, Providers, Toaster, CfAnalytics)

    **Docs manifest.ts** — Create `apps/docs/app/manifest.ts`:
    ```typescript
    import type { MetadataRoute } from 'next'

    export default function manifest(): MetadataRoute.Manifest {
      return {
        name: 'Feelr Docs',
        short_name: 'Feelr Docs',
        description: 'Documentation for Feelr — agent-friendly API simplification layer.',
        start_url: '/',
        display: 'standalone',
        background_color: '#09090b',
        theme_color: '#E85D3A',
        icons: [
          { src: '/icon-192.png', sizes: '192x192', type: 'image/png' },
          { src: '/icon-512.png', sizes: '512x512', type: 'image/png' },
        ],
      }
    }
    ```

    **Docs layout.tsx** — Update `apps/docs/app/layout.tsx`:
    1. Add `import type { Viewport } from 'next'` alongside existing `Metadata` import
    2. Add `metadataBase` to the existing metadata export:
       ```typescript
       export const metadata: Metadata = {
         metadataBase: new URL(process.env.NEXT_PUBLIC_SITE_URL ?? 'http://localhost:3000'),
         title: { ... },  // keep existing
         description: '...',  // keep existing
       }
       ```
    3. Add viewport export AFTER the metadata export:
       ```typescript
       export const viewport: Viewport = {
         themeColor: '#E85D3A',
       }
       ```
    4. Do NOT modify the Nextra Head, Navbar, Footer, or Layout components

    Important notes:
    - `process.env.NEXT_PUBLIC_SITE_URL` is read at build time by Next.js (NEXT_PUBLIC_ prefix makes it available in both server and client code, but metadataBase is server-only; the prefix is still correct since CI injects it as a build-time env var)
    - Do NOT use `metadata.themeColor` — it is deprecated since Next.js 14. Use `viewport.themeColor` via a separate `viewport` export
    - The manifest PNGs (icon-192.png, icon-512.png) were placed in each app's `public/` directory by Plan 23-01
  </action>
