<task type="auto">
  <name>Task 2: Create GitHub Actions release workflow</name>
  <files>
    .github/workflows/release.yml
  </files>
  <action>
    Create `.github/workflows/release.yml` for automated releases triggered by version tags.

    **Workflow configuration:**
    - name: `Release`
    - on: push tags `v*` (e.g., v1.0.0, v0.1.0-beta)
    - permissions: `contents: write` (needed for creating GitHub Releases and pushing to homebrew tap)

    **Job: release**
    - runs-on: `ubuntu-latest`
    - steps:
      1. **Checkout**: `actions/checkout@v4` with `fetch-depth: 0` (CRITICAL: GoReleaser needs full git history for changelog generation. Without this, it fails with "could not determine first tag" errors.)
      2. **Set up Go**: `actions/setup-go@v5` with `go-version-file: cli/go.mod` (reads Go version from the module file)
      3. **Run GoReleaser**: `goreleaser/goreleaser-action@v6` with:
        - version: `~> v2` (use latest GoReleaser v2.x)
        - args: `release --clean`
        - env: `GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}`

    The workflow is minimal by design -- GoReleaser handles everything (build, archive, checksum, changelog, GitHub Release, Homebrew formula push).

    Note: For the Homebrew tap push to work, the `GITHUB_TOKEN` needs write access to the `andrewprograde/homebrew-feelr` repository. If using a fine-grained PAT, it needs Contents: write on the tap repo. The default GITHUB_TOKEN works if both repos are in the same org/user.
  </action>
  <verify>
    - `ls .github/workflows/release.yml` -- file exists
    - `grep 'fetch-depth: 0' .github/workflows/release.yml` -- full git history for changelog
    - `grep 'goreleaser-action@v6' .github/workflows/release.yml` -- correct action version
    - `grep 'go-version-file: cli/go.mod' .github/workflows/release.yml` -- Go version from module
    - `grep "v\\*" .github/workflows/release.yml` -- triggers on version tags
    - `grep 'contents: write' .github/workflows/release.yml` -- required permissions
  </verify>
  <done>

  </done>
