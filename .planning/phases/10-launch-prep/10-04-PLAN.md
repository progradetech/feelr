    **Badges**: (placeholder format -- actual badges added when repo is public)

    **What is Feelr?** -- 2-3 paragraph overview:
    - One-line: "Feelr is an agent-friendly API gateway that lets AI agents discover and call external APIs with minimal context overhead."
    - Key value: Agents call `feelr run github issues.list repo=owner/repo` instead of reading GitHub API docs, managing OAuth tokens, and parsing nested responses.
    - How it works: Gateway normalizes requests/responses across connectors (GitHub, Slack, Stripe, Discord) into a flat JSON envelope `{ ok, data, error, meta }`.
    - Deployment options: Cloud hosted (api.feelr.dev) or self-hosted (Docker Compose).

    **Features** -- Bulleted list:
    - 4 connectors: GitHub, Slack, Stripe, Discord (30+ actions)
    - Flat JSON responses: consistent `{ ok, data, error, meta }` envelope
    - Progressive discovery: `feelr tools` shows connectors -> actions -> schemas
    - Composable actions: chain multi-step workflows via YAML (e.g., GitHub issue -> Slack notification)
    - CLI-first: single binary for all platforms (linux, macOS, Windows)
    - Self-hostable: `docker compose up` for full stack
    - Token management: encrypted credential storage with auto-refresh
    - Tiered rate limiting: free/pro/enterprise plans
    - Dashboard: web UI for key management, connector status, usage analytics

    **Quick Start** -- 4 steps:
    ```bash
    # Install via Homebrew (macOS/Linux)
    brew install andrewprograde/feelr/feelr

    # Initialize
    feelr init

    # Connect GitHub
    feelr auth github

    # Make your first call
    feelr run github issues.list repo=owner/repo
    ```

    **Installation** section with options:
    - Homebrew: `brew install andrewprograde/feelr/feelr`
    - Binary: Download from GitHub Releases
    - From source: `cd cli && go build -o feelr .`

    **Architecture** -- Brief diagram (text-based):
    ```
    Agent/CLI -> Edge Gateway -> Connector -> External API
                    |                |
                 Auth Vault    Response Normalizer
                    |                |
                  KV/DO         Flat JSON
    ```

    **Self-Hosting**:
    ```bash
    git clone https://github.com/andrewprograde/feelr.git
    cd feelr/self-host
    cp feelr.yaml.template feelr.yaml
    cp env.template .env
    # Edit .env with your secrets
    docker compose up
    ```
