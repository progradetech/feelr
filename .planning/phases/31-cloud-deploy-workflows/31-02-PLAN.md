<task type="auto">
  <name>Task 1: Fix root turbo.json for Next.js static export builds</name>
  <files>turbo.json</files>
  <action>
Update the root `turbo.json` to match what the OSS turbo.json provides for Next.js builds:

1. Add `"out/**"` to the `build.outputs` array. Next.js with `output: 'export'` writes to `out/`, not `dist/`. Without this, turbo won't cache the build output correctly. Change:
   ```json
   "outputs": ["dist/**"]
   ```
   To:
   ```json
   "outputs": ["dist/**", "out/**"]
   ```

2. Add the NEXT_PUBLIC env vars to the `build.env` array for proper cache invalidation. Turbo needs to know which env vars affect the build so it can bust the cache when they change. Add:
   ```json
   "env": ["NEXT_PUBLIC_GATEWAY_URL", "NEXT_PUBLIC_CF_ANALYTICS_TOKEN", "NEXT_PUBLIC_SITE_URL"]
   ```

The final turbo.json `build` task should look like:
```json
"build": {
  "dependsOn": ["^build"],
  "outputs": ["dist/**", "out/**"],
  "env": ["NEXT_PUBLIC_GATEWAY_URL", "NEXT_PUBLIC_CF_ANALYTICS_TOKEN", "NEXT_PUBLIC_SITE_URL"]
}
```

Do NOT modify any other tasks in turbo.json (test, typecheck, lint).
  </action>
  <verify>
- `cat turbo.json` shows `"out/**"` in build.outputs
- `cat turbo.json` shows all three NEXT_PUBLIC env vars in build.env
- `pnpm turbo run build --filter=@feelr/dashboard --dry-run` shows the dashboard package and reports the env vars as inputs
  </verify>
  <done>
Root turbo.json includes `out/**` in build outputs and all three NEXT_PUBLIC env vars in build.env. Turbo correctly recognizes dashboard build output location and will invalidate cache when env vars change.
  </done>
</task>
