<objective>
Create the CLI `feelr auth <provider>` command with OAuth browser flow for Slack and direct token input for Discord/Stripe.

Purpose: This is the user-facing auth command that connects providers. **providers.go -- Provider configuration:**
- Define `ProviderConfig` struct: `{ Name, AuthType ("oauth2" | "token"), OAuthEndpoint (optional) }`
- Slack config: AuthType "oauth2" -- the actual client_id and authorize_url are fetched from the gateway at auth time (not hardcoded in CLI)
- Discord config: AuthType "token", prompt message "Enter your Discord bot token (from Developer Portal > Bot > Token)"
- Stripe config: AuthType "token", prompt message "Enter your Stripe API key (sk_live_* or sk_test_* from Stripe Dashboard)"
- Export `GetProvider(name string) (*ProviderConfig, error)` -- returns config or error for unknown provider
- Known providers: "slack", "discord", "stripe"

**oauth.go -- OAuth flow for Slack:**
- `performOAuthFlow(gwClient *client.GatewayClient, provider *ProviderConfig) error`
- Steps:
  1. Fetch OAuth config from gateway: `GET /admin/oauth/config/slack` -- gets client_id, authorize_url, scopes
  2. Start localhost HTTP server on random available port (`net.Listen("tcp", "127.0.0.1:0")`)
  3. Build authorize URL with: client_id, scope, redirect_uri=http://127.0.0.1:{port}/callback, state=random 32-char hex string
  4. Print auth URL to stderr: `fmt.Fprintf(os.Stderr, "Opening browser to authorize Slack...\n")`
  5. Print URL for manual copy: `fmt.Fprintf(os.Stderr, "If browser doesn't open, visit:\n  %s\n\n", authURL)` (per locked decision)
  6. Try to open browser via `browser.OpenURL(authURL)` -- ignore error (headless fallback)
  7. Wait for callback on localhost server (channel-based, 5-minute timeout)
  8. Callback handler validates state param, extracts code, sends to channel, serves "Authentication successful! You can close this tab." HTML response
  9. Send code to gateway: `POST /admin/oauth/exchange/slack` with `{ code, redirect_uri }`
  10. On success: print `fmt.Fprintf(os.Stderr, "Slack connected successfully! Team: %s\n", team)`
  11. On timeout: return error "authorization timed out after 5 minutes"
  12. Shutdown localhost server gracefully

- Fallback for headless (when port unavailable or explicitly requested):
  - If `--no-browser` flag or listener fails, use manual code paste flow
  - Print URL with out-of-band redirect
  - Prompt: `fmt.Fprint(os.Stderr, "Paste the authorization code here: ")`
  - Read code from stdin
  - Send to gateway exchange endpoint

**token.go -- Direct token input for Discord/Stripe:**
- `promptToken(gwClient *client.GatewayClient, provider *ProviderConfig, tokenFlag string, connector string) error`
- Token resolution order (per locked decision: dual auth paths):
  1. `--token` flag value (if provided)
  2. Environment variable: `FEELR_{CONNECTOR}_TOKEN` (e.g., `FEELR_DISCORD_TOKEN`, `FEELR_STRIPE_TOKEN`)
  3. Interactive prompt to stderr (if terminal detected via `golang.org/x/term`)
  4. If non-interactive and no token found: error with clear instructions
- After obtaining token, store via gateway: `POST /admin/credentials/{connector}` with `{ access_token: token }` (no refresh_token, no expires_at -- these tokens don't expire)
- Print success: `fmt.Fprintf(os.Stderr, "%s connected successfully!\n", provider.Name)`

**client.go -- Add new methods to GatewayClient:**
- `GetOAuthConfig(provider string) (*OAuthConfigResponse, error)` -- GET /admin/oauth/config/:provider. Uses ADMIN_TOKEN for auth.
- `PostOAuthExchange(provider string, code, redirectURI string) (*OAuthExchangeResponse, error)` -- POST /admin/oauth/exchange/:provider. Uses ADMIN_TOKEN for auth.
- `PostAdminCredential(connector string, body map[string]interface{}) error` -- POST /admin/credentials/:connector. Uses ADMIN_TOKEN for auth.
- IMPORTANT: These admin endpoints use ADMIN_TOKEN, not the regular API key. Add an `adminToken` field to GatewayClient, populated from config. The admin auth header is `Authorization: Bearer <adminToken>`.
- Add `NewAdminClient(baseURL, adminToken string) *GatewayClient` or extend the existing client to optionally carry an admin token. The auth command needs the admin token from config.
- Define response types: `OAuthConfigResponse { ClientID, AuthorizeURL, Scopes string }`, `OAuthExchangeResponse { Connector, Status, Team string }`

**Slack subcommand** (`feelr auth slack`):
- Flags: `--no-browser` (skip browser auto-open, use manual code paste)
- RunE:

  5. On error: wrap as CLIError with appropriate exit code (2 for auth failures)
