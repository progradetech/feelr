**admin.ts -- Add OAuth config and exchange endpoints:**

Add two new routes (alongside existing credential routes, under admin auth middleware):

1. `GET /oauth/config/:provider` -- Returns OAuth config for CLI to build auth URL.
   - For 'slack': Return `{ client_id: env.SLACK_CLIENT_ID, authorize_url: 'https://slack.com/oauth/v2/authorize', scopes: 'chat:write,channels:read,search:read,users:read,channels:write.topic' }`
   - For 'discord': Return error -- Discord uses bot tokens, not OAuth. Return `{ auth_type: 'token', message: 'Discord uses bot tokens. Use --token flag or provide bot token directly.' }`
   - For 'stripe': Return error -- Stripe uses API keys. Return `{ auth_type: 'api_key', message: 'Stripe uses API keys. Use --token flag or provide your sk_* key directly.' }`
   - For unknown: 404 NOT_FOUND

2. `POST /oauth/exchange/:provider` -- Server-side token exchange. CLI sends auth code, gateway exchanges with client secret.
   - Only supported for 'slack' (others don't use OAuth)
   - Body: `{ code: string, redirect_uri: string }`
   - Gateway calls Slack's `oauth.v2.access` endpoint with: client_id (from env), client_secret (from env), code, redirect_uri
   - On success: Store credential via existing `storeCredential()` function (handles encryption + DO registration)
   - Check token response for `expires_in` field:
     - If present (rotation enabled): Store with expiresAt = now + expires_in * 1000, refreshToken from response
     - If absent (rotation disabled): Store with expiresAt = null, refreshToken = null (token never expires)
   - Return `{ ok: true, data: { connector: 'slack', status: 'connected', team: response.team.name } }`
   - On Slack error (ok: false): Return 400 with Slack's error string

Apply admin auth middleware to both new routes.

**refresh-adapters.ts -- Create refresh adapter registry:**
- Create interface `RefreshAdapter { provider: string, refresh(refreshToken: string, env: Record<string, string>): Promise<{ accessToken: string, refreshToken: string, expiresAt: number }> }`
- Implement `slackRefreshAdapter`:
  - POST to `https://slack.com/api/oauth.v2.access` with form-encoded body: client_id, client_secret, grant_type=refresh_token, refresh_token
  - Parse response, check ok field (Slack's quirk applies here too)
  - Return new accessToken, refreshToken, expiresAt (now + expires_in * 1000)
- Export `getRefreshAdapter(provider: string): RefreshAdapter | null` -- returns adapter for provider or null

**token-coordinator.ts -- Replace performRefresh stub with real logic:**
- Import `getRefreshAdapter` from `../connectors/refresh-adapters`
- In `performRefresh(token)`:
  - Get adapter via `getRefreshAdapter(token.connector)`
  - If no adapter exists (GitHub, Discord, Stripe -- their tokens don't expire or don't have refresh), log and skip
  - If adapter exists: Call `adapter.refresh(token.refresh_token, { SLACK_CLIENT_ID: this.env.SLACK_CLIENT_ID, SLACK_CLIENT_SECRET: this.env.SLACK_CLIENT_SECRET })`
  - On success: Update token row with new access_token, refresh_token, expires_at, reset retry_count to 0, status to 'active'
  - Also update KV with new encrypted credential (import encrypt from auth/crypto, write to KV at `cred:${connector}`)
  - Keep existing error handling (retry count, exponential backoff, 'failed' status)
