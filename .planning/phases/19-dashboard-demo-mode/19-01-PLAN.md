Modify all 4 hook files to intercept SWR fetches when `isDemo` is true. Use the **SWR null-key conditional fetching pattern** (Approach A from research) to satisfy React Rules of Hooks — `useSWR` must ALWAYS be called unconditionally.

**Pattern for each hook:**
1. Import `useDemo` from `@/lib/demo-context`
2. Import the relevant fixture constant(s) from `@/lib/demo-data`
3. Call `const { isDemo } = useDemo()` BEFORE `useSWR`
4. Pass `null` as the SWR key when `isDemo` is true: `useSWR(isDemo ? null : 'original-key', fetcher)`
5. After the `useSWR` call, if `isDemo`, return a spread of the SWR result with `data` and `isLoading` overridden: `return isDemo ? { ...swr, data: FIXTURE_DATA, isLoading: false } : swr`

**CRITICAL — Rules of Hooks:** NEVER return before the `useSWR` call. The null key prevents the fetch; the override after provides fixture data. This ensures hook count is stable across renders.
