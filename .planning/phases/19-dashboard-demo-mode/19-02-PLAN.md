**1. Modify `apps/dashboard/src/components/key-create-dialog.tsx`:**

- Inside `KeyCreateDialog`, call `const { isDemo } = useDemo()` (after the existing useState calls)
- In `handleSubmit`, add demo interception AFTER `e.preventDefault()` and `setIsCreating(true)` but BEFORE the try block:

```typescript
if (isDemo) {
  // Generate a fake demo key for the reveal dialog
  toast.success('Demo: API key created successfully');
  onCreated('fk_demo_' + Date.now().toString(36));
  setLabel('');
  setIsCreating(false);
  return;
}
```

- The `onCreated` callback passes a fake key string to the parent page's key reveal UI
- The `setLabel('')` resets the form state
- The `setIsCreating(false)` restores the button state
- The parent page's `mutate()` call after `onCreated` will be a no-op because in demo mode the SWR key is null (from Plan 19-01), so no network request fires
