# Requirements: Feelr

**Defined:** 2026-02-11
**Core Value:** An AI agent can call any supported external API in one line with near-zero context overhead

## v1.3 Requirements

Requirements for v1.3 Staging & Branding milestone. Each maps to roadmap phases.

### Staging Domains

- [ ] **STAGE-01**: Developer can access gateway staging at staging-api.feelr.dev
- [ ] **STAGE-02**: Developer can access dashboard staging at staging-app.feelr.dev
- [ ] **STAGE-03**: Developer can access docs staging at staging-docs.feelr.dev
- [ ] **STAGE-04**: Staging dashboard connects to staging gateway via staging-api.feelr.dev
- [ ] **STAGE-05**: CI/CD deploys dashboard staging to staging-app.feelr.dev on push to main
- [ ] **STAGE-06**: CI/CD deploys docs staging to staging-docs.feelr.dev on push to main
- [ ] **STAGE-07**: CI/CD deploys gateway staging with staging-api.feelr.dev custom domain

### Branding — Icons

- [ ] **ICON-01**: Browser tab shows Feelr logomark favicon on dashboard
- [ ] **ICON-02**: Browser tab shows Feelr logomark favicon on docs site
- [ ] **ICON-03**: iOS/Android home screen shows Feelr apple-touch-icon
- [ ] **ICON-04**: SVG icon scales correctly in modern browsers (dark/light)
- [ ] **ICON-05**: Web manifest provides app name, theme color, and icon sizes

### Branding — Logos

- [ ] **LOGO-01**: Dashboard sidebar displays Feelr logomark instead of text
- [ ] **LOGO-02**: Docs navbar displays Feelr logo instead of bold text
- [ ] **LOGO-03**: Landing page hero section includes Feelr logo
- [ ] **LOGO-04**: metadataBase is environment-aware (staging vs production URL)

## Future Requirements

None deferred from this milestone.

## Out of Scope

| Feature | Reason |
|---------|--------|
| PWA offline support | Web manifest is for branding only, not full PWA |
| Dynamic OG images | Static metadata sufficient for v1.3 |
| Staging environment indicators (banners) | Nice-to-have, defer to future |
| Automated staging smoke tests | Manual verification sufficient for now |
| Custom 404/error pages with branding | Defer to future polish milestone |
